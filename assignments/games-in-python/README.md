
# 📘 Assignment: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e seleção aleatória criando uma versão do jogo da Forca em Python.

## 📝 Tarefas

### 🛠️ Preparar a Palavra e Receber Palpites

#### Descrição
Complete o código inicial para escolher uma palavra secreta e permitir que o jogador tente adivinhá-la, acompanhando as letras corretas.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Exibir o progresso da palavra no formato `_ _ _`, revelando as letras adivinhadas corretamente.
- Solicitar palpites de letras ao jogador.

### 🛠️ Controlar as Tentativas e Encerrar o Jogo

#### Descrição
Atualize o estado do jogo após cada palpite e encerre a partida quando o jogador adivinhar a palavra ou esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Rastrear o número de tentativas incorretas restantes e reduzi-lo quando o palpite estiver errado.
- Continuar o jogo enquanto a palavra não tiver sido adivinhada e ainda houver tentativas.
- Exibir uma mensagem de vitória quando a palavra for adivinhada ou de derrota quando as tentativas acabarem.
